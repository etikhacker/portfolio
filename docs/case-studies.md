# Case Studies — Portfolio

## 1. To-Do CRUD API (todo-crud-api)
A full CRUD API built with FastAPI. Includes Swagger docs, GitHub publishing, initial SQLite
persistence, then migration to PostgreSQL + Docker. Built step by step as part of the FlyRank
Backend Track. Documented as a case study alongside a 6-version prompt iteration ladder.

## 2. E-Cədvəl / QrupTap
Multi-tenant university scheduling SaaS. Built with Next.js + Supabase + TypeScript.
Superadmin/university-admin role separation, RLS, real-time conflict detection, CSV/PDF export,
and an email invite system via Resend. Grew out of a simple HTML schedule generator originally
built for MDU's Engineering Faculty. Submitted to the ABB Innovation incubation program.
Live: e-cedvel.vercel.app

## 3. EkoAI
AI-powered energy monitoring platform with a Telegram bot. Built with React/Vite + FastAPI + Gemini API.
The bot runs through Pipedream and OpenRouter, with conversation memory and inline keyboard buttons.
Presented at the Holberton School bootcamp. Team: Vüsalə Əliyeva (frontend).
Live: energy-platform-beta.vercel.app

## 4. RentHome AZ
A rental home platform. Built with Next.js 14 + Supabase. Multilingual support (AZ/EN/RU via
next-intl), admin panel, push notifications, real-time messaging, favorites. Uses Supabase MCP
for schema migrations.
Live: rent-home-az.vercel.app
