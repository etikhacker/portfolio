## Overview

This repository contains a fast, responsive, static portfolio website with a technical, terminal-inspired visual identity. It is designed to make the following journey clear: learn who I am, review my work, and get in touch.

| Area | What it includes |
|---|---|
| Home | Personal introduction, terminal-style workflow, skills, selected projects, and calls to action |
| Projects | A structured overview of portfolio projects with descriptions, technology tags, and links |
| Contact | Direct email access and a contact form for collaboration or freelance inquiries |
| Language support | Azerbaijani and English interface switching |
| Theme support | Dark and light theme switching, saved in browser storage |

## Design System

The portfolio uses a calm, technical visual system that reflects a developer and AI-integrator identity.

| Element | Choice |
|---|---|
| Heading and UI font | JetBrains Mono |
| Body font | Inter |
| Default background | `#090c10` |
| Primary brand accent | Amber `#f0ac47` |
| Functional success color | Green `#63dd97` |
| Functional information color | Cyan `#7cc6e8` |

The amber color is reserved for brand and interactive elements. Green and cyan are used primarily for terminal states, status badges, and technical indicators.

## Local Development

The site is a static project and does not require a package installation step.

```bash
git clone https://github.com/etikhacker/portfolio.git
cd portfolio
```

Open `index.html` in a browser, or run it with a local static server:

```bash
python3 -m http.server 8000
```

Then visit [http://localhost:8000](http://localhost:8000).
